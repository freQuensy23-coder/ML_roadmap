# Короткий ответ

Можно нормализовать значение TF IDF по всем элементам в документе, что бы они суммировались в 1 (или сумма квадратов была 1)

Ниже развернутый ответ:

# Что такое нормализация в TF-IDF?

## Зачем нужна нормализация?

**Проблема:** Длинные документы получают "несправедливое преимущество" при сравнении.

Представьте три документа:
- **Короткий:** "кот сидит" (2 слова)
- **Средний:** "кот сидит на дереве" (4 слова) 
- **Длинный:** "кот сидит на высоком зеленом дереве и смотрит на птиц во дворе" (14 слов)

После TF-IDF длинный документ содержит больше ненулевых значений → его вектор имеет бОльшую "сумму" → он кажется более релевантным любому запросу просто из-за размера.

**Без нормализации** мы сравниваем размер документов, а не содержание.

## Виды нормализации

### L2 нормализация (по умолчанию)
**Суть:** Приводит все векторы к единичной длине.

**Формула:** `vector / sqrt(сумма_квадратов)`

**Пример:** [3, 4, 0] → [0.6, 0.8, 0] (длина = 1)

**Интуиция:** Все документы получают "одинаковую силу", сравниваем только направление в пространстве признаков.

### L1 нормализация
**Суть:** Приводит сумму элементов к единице.

**Формула:** `vector / сумма_абсолютных_значений`

**Пример:** [3, 4, 0] → [0.43, 0.57, 0] (сумма = 1)

**Интуиция:** Превращает вектор в вероятностное распределение — доли важности каждого слова.

## Практический пример

**Задача:** Найти документы похожие на запрос **"кот"**

### Без нормализации:
```
Короткий "кот сидит": сходство = 0.46
Средний "кот сидит на дереве": сходство = 0.73  
Длинный документ про кота: сходство = 0.89
```
**Проблема:** Длинный документ "выигрывает" из-за размера, а не содержания.

### С L2 нормализацией:
```
Короткий "кот сидит": сходство = 1.00 ✅
Средний "кот сидит на дереве": сходство = 0.71
Длинный документ про кота: сходство = 0.41
```
**Результат:** Короткий документ справедливо получил максимальную релевантность.

## Когда что использовать?

| Нормализация | Применение |
|--------------|------------|
| **L2** | Поиск, кластеризация, большинство задач (по умолчанию в scikit-learn) |
| **L1** | Когда нужна интерпретируемость (веса = доли важности) |
| **Без нормализации** | Редко, когда длина документа важна для задачи |

## Ключевые факты

✅ **L2 нормализация** убирает влияние длины документа  
✅ **После L2** косинусное сходство = скалярному произведению (упрощает вычисления)  
✅ **В scikit-learn L2 по умолчанию** — хороший выбор для старта  
✅ **Нормализация** позволяет сравнивать содержание, а не размер документов

**Главная мысль:** Нормализация делает сравнение документов справедливым!
